# Phase 1 results: prompt-order fix + visual-token budget 140 (2026-10-21)

Commit under test: `088fc18`. Weights `config.txt`: `vision_default_output_length=140` (baseline 280).
Same device, build configuration, inputs and protocol as `baseline-2026-10-21.md`; 3 rounds.

## Phase 1 targets

| Metric | Baseline (5 rounds) | Phase 1 (3 rounds) | Change |
|---|---|---|---|
| Prompt dropped (9 prefill tokens) | 9/26 text inferences (35 %) | **0/11** | eliminated |
| Run-to-run determinism | same input gave different token counts per launch | identical prefill/decode token counts in rounds 2 and 3 for every inference | restored |
| Vision `std::bad_alloc` | 5/10 scans | **0/6** | eliminated |
| Health-scan peak footprint, median | 2,065 MB | **1,774 MB** | -14 % |
| Health-scan peak footprint, max | 2,206 MB | **1,796 MB** | -19 % |
| Lowest jetsam headroom (limit 3,072 MB) | 866 MB | **1,276 MB** | +47 % |
| Finance received full prompt | 0/5 | **3/3** (594 prefill tokens) | fixed |

## Side effects (to address in phase 2)

| Metric | Baseline | Phase 1 |
|---|---|---|
| Finance summary | 2.6-14.3 s, prompt dropped or truncated | 52.7 s median, real output |
| Health scan, median of all scans | 140.0 s | 180.3 s |
| Health scan IMG_9603 | 130.9 s | 115.6 s |
| Health scan IMG_9596 | 147.2 s | 373.4 s (vision JSON invalid, repair invalid, OCR, reload, text structuring invalid) |
| Insights | 171.2 s | 294.7 s (first attempt now fails JSON parsing in rounds 2-3, retry succeeds) |
| Vision TTFT | 17.2 s | 16.8-24.3 s (no speed-up from fewer patches) |

With full prompts the model now produces long structured outputs, and many of them fail Spendy's JSON parsing,
which triggers repair inferences, a model reload and retries.

## Extraction accuracy

| Round | IMG_9603 | IMG_9596 |
|---|---|---|
| 1 | 0/8, 5 wrong values | 2/8, 5 wrong or invented items |
| 2 | 2/8, about 10 invented items (Sodium, Potassium, BUN, Creatinine, Insulin...) | 1/8, 1 wrong value (OCR fallback) |
| 3 | 2/8, 5 wrong values, 1 invented item | 1/8, 1 wrong value (OCR fallback) |

The vision path now completes but invents plausible-looking values (for example LDL 140, HDL 45, Triglycerides 150).
It is not possible to separate the effect of the lower visual-token budget from the effect of the vision prompt now
arriving intact; baseline round 5 (budget 280) also invented 4 values.
